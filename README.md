# Босния 2026 — план путешествия

Рабочий репозиторий поездки: Москва → Белград → Босния и Герцеговина, **31 июля – 12 августа 2026** (боснийская часть: 4–11.08, вдвоём, аренда машины).

Маршрут: Сараево (3 ночи) → Умоляни → Лукомир, самая высокогорная деревня Боснии (2 ночи, медитативный день на кромке каньона Ракитницы) → приватный квадро-тур из Коньица → Борачко озеро (2 ночи, домик с собственным понтоном) → перелёт домой. Главные истории: параглайдинг над Сараево, квадры вокруг каньона, жизнь в каменной деревне на 1470 м.

## С чего начать

**[bosnia_trip_plan.md](bosnia_trip_plan.md)** — главный хаб: календарь с перелётами, рамка маршрута, статус всех броней, бюджет, открытые вопросы, заготовки сообщений операторам. Всегда отражает актуальное состояние поездки.

**Веб-версия** (карта маршрута, фото-карусели, тайминги) — приватный артефакт: https://claude.ai/code/artifact/5be2e2e3-f29e-45ea-9bf7-ce1cb518da11 · локальная копия: [site/bosnia_trip.html](site/bosnia_trip.html) (самодостаточный файл, открывается без интернета).

## Как это устроено

План собирался итеративно с Claude Code: ресёрч операторов и жилья по свежим данным (цены и контакты в файлах — с датами проверки), затем брони. История решений — в коммитах: почему выпал Мостар, как квадры переехали в Коньиц, когда какая бронь закрылась.

Правки вносить в `bosnia_trip_plan.md` и файлы дней; веб-страница пересобирается из [site/template.html](site/template.html) скриптом `site/build.py` (фото вшиваются data-URI, внешних запросов страница не делает).
