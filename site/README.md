# Веб-страница поездки «Босния — 9 дней»

Опубликована как артефакт: https://claude.ai/code/artifact/5be2e2e3-f29e-45ea-9bf7-ce1cb518da11

## Файлы
- `bosnia_trip.html` — **готовая собранная страница** (~2.8 МБ, самодостаточная: все 28 фото и карта вшиты). Открывается локально двойным кликом, интернет не нужен
- `template.html` — исходник вёрстки: контент, стили, JS каруселей; фото — плейсхолдеры `{{имя}}`, карта — `MAPSVG_PLACEHOLDER`
- `build.py` — сборщик: вставляет карту и фото (data-URI) в шаблон → `bosnia_trip.html`
- `make_map.py` — генератор SVG-карты маршрута из геоданных и координат
- `coords.json` — проверенные координаты всех точек маршрута (lat/lon)
- `map_fragment.svg` — сгенерированная карта (пересоздаётся make_map.py)
- `geo_*_hi.json` — контуры стран (geoBoundaries ADM0 simplified)
- `fetch_imgs.py` — скрипт загрузки фото с Wikimedia Commons (лицензии свободные)
- `web/` — 28 фото, ужатых до 800px/q42 под вшивание

## Как пересобрать после правок
```bash
cd site
python3 make_map.py   # только если менялась карта/координаты
python3 build.py      # соберёт bosnia_trip.html
```
Публикация обновления — через Claude: перепубликовать файл в тот же артефакт (URL сохранится).

## Ограничения хостинга (артефакта)
Один самодостаточный HTML: никаких внешних запросов (CDN, шрифты по ссылке, внешние картинки). Всё инлайном/data-URI. Обе темы (светлая/тёмная) через CSS-переменные. Подробнее — ../design_brief_trip_page.md
